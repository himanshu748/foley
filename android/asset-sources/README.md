# Launcher artwork provenance

`tv_banner.png` and `ic_launcher.png` are original code-drawn Foley wordmark assets. They use the product's cream/ink/burnt-red palette and Bricolage Grotesque / DM Sans fonts from the installed `@fontsource` packages. Font licenses are retained in this directory.

The artwork is reproducible with `node scripts/create-launcher-assets.mjs` from the app root, using installed Playwright Chromium. The 320×180 English banner includes the app name and the 512×512 icon is its lowercase f mark. These are launch assets, not screenshots or proof of Android execution.
